Atividade Pratica

Esta atividade prática simula o gerenciamento do banco de dados de um E-commerce de Eletrônicos. Ela aborda cenários reais onde o uso de UPDATE e DELETE é necessário, reforçando a importância do uso do filtro WHERE para evitar alterações indesejadas.

Atividade Prática: Gestão do E-Commerce;
Copie e execute o código abaixo no seu SGDB (MySQL) para tabela de produtos.



#Criação da tabela

CREATE TABLE produtos (
    id INT PRIMARY KEY,
    nome VARCHAR(50),
    categoria VARCHAR(30),
    preco DECIMAL(10, 2),
    estoque INT,
    status VARCHAR(20)
);
